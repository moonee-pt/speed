# AICosplay

AI驱动的Cosplay应用项目

## 项目介绍

这是一个使用AI技术的Cosplay应用，前后端分离架构设计。

## 技术栈

### 前端
- React 18
- Vite
- Ant Design
- Axios

### 后端
- Node.js
- Express
- MongoDB
- Mongoose
- JWT

## 项目结构

```
speed/
├── frontend/        # 前端React应用
├── backend/         # 后端Express服务
├── .gitignore       # Git忽略文件
└── README.md        # 项目说明文档
```

## 开发指南

### 前端开发

```bash
cd frontend
npm install
npm run dev
```

### 后端开发

```bash
cd backend
npm install
npm run dev
```

## 注意事项

- 确保MongoDB服务已启动
- 后端使用的数据库连接信息已在.env文件中配置
